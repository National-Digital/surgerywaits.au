## Government data in the repository

The tests read small extracts cut from real publicdata.au versions, so the suite runs without a
download. Each extract is redistributed under its publisher's licence with the attribution that
publicdata.au gives for that version. The extracts are in `pipeline/tests/fixtures/`, and
`pipeline/tests/fixtures/manifest.json` records each source file's SHA-256, each extract's
SHA-256 and row count, and its attribution. A test checks the manifest against the files.
`pipeline/scripts/make_fixtures.py` cuts them. Each extract keeps only the rows for a handful of
hospitals in New South Wales, Victoria and Queensland, so it is a subset of the published data.
The extracts and this notice do not imply endorsement by the publisher.

## Government data the site serves

None of it is in this repository. The site reads immutable dated versions of datasets from
publicdata.au, pinned to a version. The licence and attribution for each source are in
[`LICENSE-DATA.md`](LICENSE-DATA.md) and on the pages that show its figures.

## Typefaces, libraries and marks

None are committed to the repository yet. Packages installed at build time from lockfiles keep
their own licences. A font, an icon set or any other asset that is committed is listed here in
the pull request that adds it.
