# Architecture

surgerywaits.au is a static site that shows public hospital planned-surgery waiting times. It takes
all its data from [publicdata.au](https://publicdata.au/) and has no other source.

## Status

This repository is being rebuilt. Each part below is marked as planned until it exists. A part
that is not yet built is described as it will be, and this page changes as each part lands.

## The planned shape

```
publicdata.au        dated, immutable data files, each with a sha256 in a manifest
      |
pipeline/            Python 3.13 data build (planned)
      |
dist                 output files, each validated against a JSON Schema in contract/ (planned)
      |
site/                Astro, static output, strict TypeScript (planned)
      |
Cloudflare Worker    serves the static assets (planned)
```

- **publicdata.au.** The build reads immutable dated version files at
  `https://publicdata.au/d/<slug>/v/<date>/data.parquet`. It checks each file against the sha256
  pinned in a manifest. A refresh finds new versions through the service's versions endpoint at
  `/api/v1/datasets/<slug>/versions`. Suppressed and empty cells arrive as nulls, and a `markers`
  column keeps the publisher's code for each emptied cell. That code gives the reason the site
  shows: "<5" means too few patients, "-" means no patients reported, and "NP" means AIHW did not
  publish. "Not peered" appears only in place of the peer-group columns and the site shows it as
  "not published: no peer group comparison". The Queensland tables carry no markers. A column
  named in their `suppressed` list is "not published: Queensland Health gave no figure", and a
  null in the prior-year change column that the list does not name is "not reported". Any other
  unflagged null fails the build. The credit line uses the citation that publicdata.au publishes
  with each version.
- **`pipeline/` (planned).** A Python 3.13 package built with uv, and checked with ruff, pyright
  in strict mode and pytest. It turns the pinned files into the output files. Its derive step
  builds ranks, trends and a nearby mesh: each located hospital gets its 8 nearest open public
  hospitals by great-circle distance, searched out to 250 km and doubled until 8 are found, across
  state borders and stopping at the Earth's half-circumference. Neighbours are always open
  hospitals, and a closed hospital still gets a mesh so its page can point to open ones. A
  hospital with no coordinates gets no mesh and is listed as such.
- **`contract/`.** JSON Schemas that define every file in the output. The pipeline validates each
  file against its schema before it writes anything, and the site reads from them. A figure is
  published, not published or not reported: a published one has a value, and the others have a
  reason and no value. Every figure carries its reference period and release date.
- **`site/` (planned).** An Astro project with static output. It consumes only the pipeline's
  output. `site/src/lib/dist.ts` reads it from the absolute directory in `SURGERYWAITS_DIST`, which
  has no default, so a build never reads a dist by accident. Each file is validated against its
  schema in `contract/` with Ajv, pinned exactly, and a file that fails stops the build. The folder
  a file sits in decides its schema, and a path the contract does not describe fails. The checks
  that need a dist use a small one that `pipeline/tests/fixture_dist.py` builds from the pipeline's
  fixtures. It is deterministic and never committed. `npm test` reads it from
  the `dist-fixture` folder in `pipeline/` when the variable is unset, and the `Site checks` and `Accessibility`
  jobs build it before they use it. The `Worker build` job builds the site from the same fixture dist. The real dist is not built in
  those jobs, because it takes the pinned downloads, so the `Data checks` job builds the site from it
  and runs the built-page tests on the result.
  `TrendChart` draws a series as a static inline SVG line chart, with optional benchmark lines. A withheld year is a
  gap in the line and a cross in a strip above the plot, never a zero. Series differ by dash and marker shape as
  well as hue, the picture has `role="img"` and an accessible name, and the caption states the period range and
  release. Every chart holds its figures as a data table in a native `details` element. `WaitBars` draws horizontal
  bars in the order the caller gives, labels each with its value and draws no bar for a withheld one. Both ship no
  script and render the same bytes on every build.
  Each public hospital with figures has a page at `/hospital/<slug>/`, the address the earlier site used, built from
  `hospitals.json` and the hospital files. It holds breadcrumbs, an "About this hospital" card, tiles for each
  urgency category, a table for procedures and one for specialties, trend charts, the Queensland Health quarter
  where one exists, the nearest open hospitals, the safety block and the data passport. A closed hospital says so. Its title,
  description and every sentence come from `site/content/templates/hospital.yaml`, and the canonical address
  comes from `site/content/site.yaml`.
  Each surgery has a hub page at `/surgery/<slug>/`, a page for each state with a hospital row at
  `/surgery/<slug>/<state>/`, and, where two or more hospitals of one place report it, a page at
  `/surgery/<slug>/near/<place>/`. These are the addresses the earlier site used, and a procedure keeps the
  everyday-name slug it had (`site/content/surgery-names.yaml`). `/surgery/` lists every surgery, and each specialty
  has a hub and state pages under `/specialty/<slug>/`, which the earlier site did not have. A place is a health network
  with its main hospital in `site/content/areas.yaml`. Its page lists the network's hospitals within 25 km of that
  hospital and up to two others within 25 km of one of them, and the place keeps its pages only when at least three
  procedures give it one. A hub holds the national figures as tiles, a table of the states, a table of hospitals
  ordered by median wait, a median-wait chart for Australia and the three states that treated the most patients,
  the exclusion statement, the safety block and the data passport. Ranks are the dist's national ranks. A hospital row
  whose figures are from another period is marked and never ranked. All copy is in `site/content/templates/surgery.yaml`.
  Each current row of each procedure has a pair page at `/hospital/<hospital>/<surgery>/`, with the surgery's
  everyday-name slug, as the earlier site had. It holds the hospital's figures as tiles with national ranks, the state and
  national rows beside them, the hospitals on its nearby list (up to eight) that published a shorter median, the hospital's own history for the surgery, a median-wait chart, links up to the hospital, the surgery and the state page, the exclusion
  statement, the safety block and the data passport, under the compact footer, from `site/content/templates/pair.yaml`.
  A pair is thin, and carries `noindex,follow`, when its median is not published, or when it has no earlier published year, no
  open hospital in its own nearby mesh with a published median, no long-wait share beside a national one and no nearest area
  in its state. `indexablePairPaths()` lists the rest for the sitemap. The Built pages test counts the thin pairs again from the dist.
  `/hospitals/` lists every public hospital in `hospitals.json` once, by state or territory and then A to Z. It marks a closed
  hospital with the word "Closed", gives each hospital's count of surgery types with a current figure and with only an earlier one,
  shows other names in small type, says how many hospitals are reporting and how many are not, and states the reference period
  and release date of the register those counts come from. It jumps between states with in-page anchors. The `/surgery/` list
  also shows the urgency categories in the order 1, 2, 3 and jumps to each group, and its period and release are stated once.
  Both pages state the private hospital exclusion and ship no script. `/hospitals/` comes from
  `site/content/templates/hospitals.yaml`, and the `/surgery/` additions come from `surgery.yaml`. The hospital page adds its
  "Hospitals" crumb once `/hospitals/` is built.
  `/state/` lists each state or territory with a state file, and `/state/<code>/` holds the state's median wait for its three
  busiest procedures beside the national one, a table of its open public hospitals by the median wait for each urgency
  category with the dist's national ranks, a table of its procedures and one of its specialties beside the national
  figures, links to each surgery's page for the state, to its urgency pages and to every hospital, the exclusion statement,
  the safety block and the data passport. The Queensland page adds a separate table of the Queensland Health quarter for
  the hospitals that joined a national one, in name order and never ranked. `/urgency/` explains the three categories from
  `site/content/templates/urgency.yaml`, and `/urgency/category-<n>/` and `/urgency/category-<n>/<code>/` rank the open
  public hospitals by the share treated within the recommended time, highest first, on current published figures only.
  The urgency table publishes no national or state figure, so a category page says so, and shows the figures and the trend
  only when the dist carries them. These are the addresses the earlier site used. Copy is in `templates/state.yaml` and
  `templates/urgency.yaml`, and `/surgery/` links each urgency category to its page.
  `/health-service/` lists each local hospital network that has a network file, by state or territory, and
  `/health-service/<slug>/` lists its public hospitals in name order with their state, the number of surgery types each reported in the newest period,
  and the share of urgent patients treated on time. A member whose latest urgent figures are older than the newest period shows
  no value and its own period and release, and a member with no urgent figure says so. The page ranks nothing. Each member links
  to its hospital page, and a hospital page links to its network. These are the addresses the earlier site used, and the copy is in
  `site/content/templates/health-service.yaml`. The Built pages test compares the addresses with the earlier site's list.
  `/methodology/`, `/data/` and `/about/` are the addresses the earlier site used. Each is one YAML file in `site/content/pages/`
  with its own schema. The methodology states each number the pipeline and the site use, and `site/src/contracts/content-pages.test.ts`
  fills the copy from the constants the code exports. The numbers and names that live in the pipeline reach the copy through `rules.json` in the dist, which the pipeline writes from its own constants (`pipeline/tests/test_rules.py`) and the site reads against `contract/rules.schema.json`. The data page shows every dataset in `credits.json` through the data
  passport, and the Built pages test compares them with `data/manifest.json`. The word "elective" appears only in the methodology and in the titles and citations that the data passport quotes from the publishers, and `terms.yaml` lists each of those quotes.
  `npm run build:preview` adds a development page for the figure, the stat tile, the data table, the chart, the wait bars, the safety block, the breadcrumbs and the data passport at
  `/dev/primitives/` and writes to a `dist-preview` folder in `site/`, so the published build never holds it. The
  page is marked noindex and the `Accessibility` job audits it. The base layout holds the header with the site navigation inline, the footer and, on narrow screens, a "Compare near you" bar. A link in the header, the footer or the bar comes from `site/content/navigation.yaml` and is left out until its page is built.
- **Worker.** A Cloudflare Worker with static assets serves the built site. It sets the security headers and the cache rules on every response, and answers each address in `data/redirects.json` with a 301. The build writes `sitemap.xml` and one `sitemap-<family>.xml` per page family (the pairs in files of 5,000) after the pages, listing each built page that is not marked noindex, dated with the newest data release. `site/public/robots.txt` points at the index.

## Rules that decide the code

[ADR 0001](adr/0001-architecture-decision-register.md) records why each rule exists. Each rule is
one line and ends with what enforces it. A reference has one of three forms: a pytest function,
`` `path::test_name` ``; a vitest test, `` `path` › "title" ``; or a CI job, ``CI job `Name` ``. A
reference to a test that does not exist yet, a vitest `it.todo` or a skipped pytest, ends with
"(planned)", and the marker is dropped when the test becomes real. `pipeline/tests/test_docs.py`
fails when a reference is malformed, names a test, title or job that does not exist, or has a
planned marker that does not match the test.

- **Two halves, one boundary.** `pipeline/` (Python) builds the data, `site/` (TypeScript) is the front end, and the site reads only the pipeline's dist output, validated against `contract/`. — enforced by `site/src/contracts/gates.test.ts` › "validate against their JSON Schemas in contract/"; `site/src/contracts/gates.test.ts` › "the site reads only the pipeline's dist output"; `site/src/lib/dist.test.ts` › "rejects a withheld figure that carries a number"; `site/src/lib/dist.test.ts` › "rejects a reason the contract does not list".
- **Determinism.** Nothing in dist holds a wall-clock value, a random value or unordered iteration, and two builds are byte-identical. — enforced by `pipeline/tests/test_contracts.py::test_building_twice_gives_byte_identical_dist`; `pipeline/tests/test_contracts.py::test_no_wall_clock_values_in_dist`; `pipeline/tests/test_dist.py::test_a_build_under_a_frozen_clock_is_byte_identical`; `pipeline/tests/test_gates.py::test_a_timestamp_or_unknown_date_in_dist_fails_the_clock_scan`; `pipeline/tests/test_dist.py::test_no_file_holds_a_date_or_time_outside_the_sources`; `pipeline/tests/test_dist.py::test_the_hash_seed_does_not_change_the_fixture_build`; `site/src/contracts/determinism.test.ts` › "building the site twice gives byte-identical output"; CI job `Worker build`; CI job `Data checks`.
- **One source.** Data comes only from publicdata.au's pinned dated versions, each verified by sha256, with no fallback. — enforced by `pipeline/tests/test_contracts.py::test_manifest_entry_pins_slug_version_and_sha256`; `pipeline/tests/test_contracts.py::test_download_with_wrong_digest_fails_closed`.
- **Suppressed values.** A suppressed cell renders "not published" with the publisher's reason, never 0, blank or a rank. The three reasons apply to a hospital's own figures: "<5" means too few patients, "-" means no patients reported and "NP" means AIHW did not publish. — enforced by `pipeline/tests/test_contracts.py::test_every_null_has_a_publisher_marker_or_is_reported`; `pipeline/tests/test_contracts.py::test_every_marker_maps_to_a_known_reason`; `pipeline/tests/test_suppression.py::test_the_pinned_releases_pass_suppression_in_full`; CI job `Data checks`; `site/src/contracts/gates.test.ts` › "render 'not published' with the reason taken from the publisher's marker (<5, -, NP); an unknown marker fails the build"; `site/src/contracts/gates.test.ts` › "a suppressed cell is never rendered blank or as 0"; `site/src/components/figure.test.ts` › "renders not reported in words with no number"; `site/src/components/data-table.test.ts` › "shows a withheld cell in words and a published zero as zero"; `site/src/components/stat-tile.test.ts` › "shows a published zero as zero and a negative change with its sign"; `site/src/components/trend-chart.test.ts` › "leaves a gap for a withheld point and never plots it at zero"; `site/src/components/trend-chart.test.ts` › "gives the table the same figures as the chart, with withheld cells in words"; `site/src/components/wait-bars.test.ts` › "draws no bar for a withheld value".
- **Dist contract.** Every dist file is validated against its schema in `contract/` before any file is written, and one that fails stops the build. A figure is a tagged union: published with a value, or not published or not reported with a reason and never a value. Every figure carries its period and release date, and a rank carries the number of hospitals it is out of. A trend, which a schema cannot check alone, has one point for each period, each period starting with its point's year, years that strictly increase, each period ending the year after it starts, and no change on its first point or beside a year with no published point before it. A hospital that skips a year leaves a gap, which is allowed because its series lists only the periods it reported, and a change after a gap is null. — enforced by `pipeline/tests/test_gates.py::test_a_trend_with_the_wrong_number_of_points_fails`; `pipeline/tests/test_gates.py::test_a_period_that_does_not_start_with_its_year_fails`; `pipeline/tests/test_gates.py::test_years_that_do_not_increase_fail`; `pipeline/tests/test_gates.py::test_a_first_point_with_a_change_fails`; `pipeline/tests/test_gates.py::test_a_period_ending_in_the_wrong_year_fails`; `pipeline/tests/test_gates.py::test_a_change_without_a_published_previous_year_fails`; `pipeline/tests/test_dist.py::test_a_bad_figure_is_rejected`; `pipeline/tests/test_dist.py::test_a_bad_measure_is_rejected`; `pipeline/tests/test_dist.py::test_the_fixture_dist_validates_and_counts_its_own_files`; `pipeline/tests/test_dist.py::test_a_file_that_breaks_its_contract_stops_the_build_before_anything_is_written`; `pipeline/tests/test_dist.py::test_a_ranked_figure_comes_with_its_cohort_and_a_suppressed_one_is_never_ranked`; `pipeline/tests/test_dist.py::test_the_real_dist_builds_twice_to_the_same_checksums_and_reports_its_size`; `pipeline/tests/test_dist.py::test_every_manifest_entry_the_build_reads_is_credited_and_every_listed_source_exists`; `pipeline/tests/test_dist.py::test_the_real_dist_credits_every_source_and_holds_no_stray_dates`; `pipeline/tests/test_dist.py::test_a_failure_part_way_through_writing_leaves_the_previous_dist_untouched`; `pipeline/tests/test_dist.py::test_every_real_rank_sits_inside_its_cohort`; `pipeline/tests/test_dist.py::test_every_real_trend_change_is_the_difference_of_two_published_points`; `pipeline/tests/test_dist.py::test_every_real_hospital_surgery_says_whether_it_is_stale`; CI job `Data checks`.
- **Licences.** Every manifest entry carries a licence on the allow-list (CC BY 4.0 or CC BY 3.0 AU), every credit in `credits.json` equals its manifest entry, and every dist file cites only credited sources. — enforced by `pipeline/tests/test_contracts.py::test_licence_is_on_the_allow_list`; `pipeline/tests/test_gates.py::test_the_allow_list_matches_the_manifest_schema`; `pipeline/tests/test_gates.py::test_every_credit_matches_the_manifest_and_carries_an_allowed_licence`; `pipeline/tests/test_gates.py::test_a_credit_that_drifts_from_the_manifest_is_caught`; `pipeline/tests/test_gates.py::test_a_file_citing_an_uncredited_source_is_caught`; `pipeline/tests/test_gates.py::test_a_malformed_credit_raises_a_gate_error`; `pipeline/tests/test_gates.py::test_a_file_without_sources_is_caught`.
- **Freshness.** The build reads no clock, so a pinned version is judged against its own data. A national table's `release` must be its `as_at` date written without dashes, its pinned version must not predate that date, and its newest period must start in the release year or up to 2 years before it. Every table must have a period and an empty set fails. A Queensland quarter must end on or before its release and no more than 200 days before it, because quarterly figures appear within a quarter of its end (the pinned quarter took about 70 days). Freshness is relative to each pin's own release, so a pin that has fallen behind its publisher cannot be caught offline; the scheduled refresh will catch that. — enforced by `pipeline/tests/test_gates.py::test_the_fixture_build_is_fresh`; `pipeline/tests/test_gates.py::test_a_table_too_old_for_its_release_fails`; `pipeline/tests/test_gates.py::test_a_release_that_disagrees_with_its_as_at_fails`; `pipeline/tests/test_gates.py::test_a_version_older_than_its_release_fails`; `pipeline/tests/test_gates.py::test_a_table_with_no_release_fails`; `pipeline/tests/test_gates.py::test_a_queensland_quarter_outside_its_release_fails`; `pipeline/tests/test_gates.py::test_a_build_with_a_stale_table_stops_before_rendering`; `pipeline/tests/test_gates.py::test_freshness_needs_every_table_and_a_non_empty_map`; `pipeline/tests/test_gates.py::test_a_released_dataset_outside_the_tables_is_checked_for_agreement`; `pipeline/tests/test_gates.py::test_the_pinned_releases_are_fresh`; CI job `Data checks`.
- **Slugs.** Every hospital slug is unique and URL-safe (lower-case letters, digits and single hyphens), each surgery slug is unique within its kind (each kind has its own URL directory) and matches its index entry, each suburb code is unique and a network code is URL-safe as written and keeps one name. — enforced by `pipeline/tests/test_gates.py::test_hospital_slugs_must_be_unique_and_url_safe`; `pipeline/tests/test_gates.py::test_surgery_slugs_are_unique_within_their_kind`; `pipeline/tests/test_gates.py::test_surgery_files_must_match_the_index_and_be_url_safe`; `pipeline/tests/test_gates.py::test_a_network_code_is_checked_for_url_safety_as_written`; `pipeline/tests/test_gates.py::test_suburb_codes_are_unique_and_a_network_keeps_one_name`; `pipeline/tests/test_contracts.py::test_slugs_are_unique`.
- **Coordinates.** A hospital's coordinates fall inside Australia or the build fails. — enforced by `pipeline/tests/test_contracts.py::test_coordinates_fall_within_australia`.
- **Hospital joins.** The waiting-times tables name hospitals instead of coding them, so each hospital row joins to one register code on its name, state and alternative names, and an unmatched or ambiguous row fails the build. — enforced by `pipeline/tests/test_contracts.py::test_unmatched_or_ambiguous_hospital_join_fails`; `pipeline/tests/test_waiting_times.py::test_the_pinned_releases_join_in_full`; CI job `Data checks`.
- **Not peered.** "Not peered" appears only in place of the peer-group columns, AIHW does not define it, and the site shows it as "not published: no peer group comparison" with no other meaning. — enforced by `site/src/contracts/gates.test.ts` › "'not peered' shows as 'not published: no peer group comparison' and only in place of the peer-group columns".
- **Reference period and release date.** Every rendered figure carries both, or it does not ship. — enforced by `site/src/contracts/gates.test.ts` › "every rendered figure shows its reference period and the data release date"; `site/src/components/figure.test.ts` › "fails the build for a figure that cannot state its period and release"; `site/src/components/data-table.test.ts` › "has a caption that carries the period and release once"; `site/src/components/trend-chart.test.ts` › "states the period range and the release in a visible caption"; `site/src/components/wait-bars.test.ts` › "states the period and release once"; `site/src/contracts/hospital-page.test.ts` › "state a period and release on every figure, table and chart".
- **Terminology.** "Planned surgery" names the category, copy and URLs say "surgery", and "elective" appears only where the methodology quotes a source. — enforced by `site/src/contracts/gates.test.ts` › "'elective' appears only where the methodology quotes a source"; `site/src/contracts/gates.test.ts` › "the terminology check catches a replaced term and honours a quote listed for its page"; `site/src/contracts/built-pages.test.ts` › "use no term the terms file replaces".
- **Data passport.** A page lists each source it draws on from `credits.json`: the dataset's title linked to its publicdata.au version page, the publisher, the version and release dates, the licence linked to its deed, and the citation that publicdata.au publishes with that version, exactly as `credits.json` has it (ADR 0001 D2). The manifest carries the title, publisher and page URL, and the build checks them against each file's publicdata metadata. A source with no credit fails the build. The safety block reuses the footer's safety wording; a page may hold more than one only if each has its own `id`, and breadcrumbs carry no JSON-LD because structured data is a later phase. — enforced by `site/src/components/data-passport.test.ts` › "lists every source a file draws on, with the citation verbatim"; `site/src/components/data-passport.test.ts` › "fails the build when a source has no credit"; `site/src/components/safety-block.test.ts` › "holds no script and no copy of its own"; `site/src/components/breadcrumbs.test.ts` › "holds no script, no JSON-LD and no copy of its own".
- **Ordering.** Hospitals are ordered by measured numbers only, never on suppressed, not-reported,
  closed or stale figures, with no "best hospital" language and no practitioner promotion. A rank
  is a competition rank (1, 2, 2, 4) over one category in the newest period of its table: a lower
  median wait or long-wait share ranks first, a higher on-time share ranks first, and a volume is
  never ranked. A figure is stale when its hospital's latest period for that category is older
  than the newest period in the table.
  — enforced by
  `pipeline/tests/test_contracts.py::test_no_ranking_uses_suppressed_or_stale_rows`;
  `site/src/contracts/gates.test.ts` › "a hospital with suppressed, closed or stale figures (latest period older than the newest in the table) is never ranked";
  `site/src/components/data-table.test.ts` › "ranks only a current published cell";
  `site/src/components/stat-tile.test.ts` › "never ranks or compares a stale figure";
  `site/src/components/stat-tile.test.ts` › "never ranks or compares a figure the source withheld";
  `site/src/components/stat-tile.test.ts` › "shows a stale figure with an earlier period note and its own older period";
  `site/src/contracts/gates.test.ts` › "no 'best hospital' or practitioner-promotion language appears";
  `site/src/contracts/built-pages.test.ts` › "rank no stale, withheld or closed figure";
  `site/src/contracts/surgery-page.test.ts` › "order every hospital table by the measured median, shortest first";
  `site/src/contracts/surgery-page.test.ts` › "rank only a current published figure, and no benchmark".
- **Suburb centres.** Each suburb's centre is the area centroid of its ABS shape when that lies inside the shape and otherwise the pole of inaccessibility of its largest part, rounded to 5 decimal places, special-purpose codes are excluded, and a suburb without a shape or a name shared twice within a state fails the build ([ADR 0002](adr/0002-suburb-centre-points.md)). The real-data check runs in CI against the pinned files. — enforced by `pipeline/tests/test_suburbs.py::test_pinned_boundary_file_gives_every_suburb_a_centre`; `pipeline/tests/test_suburbs.py::test_centroid_of_a_concave_shape_is_its_area_centroid`; `pipeline/tests/test_suburbs.py::test_fixture_suburbs_whose_centroid_is_outside_get_a_point_inside`; `pipeline/tests/test_suburbs.py::test_special_purpose_codes_are_excluded`; `pipeline/tests/test_suburbs.py::test_a_row_without_a_shape_fails`; `pipeline/tests/test_suburbs.py::test_a_name_shared_within_a_state_fails`; CI job `Data checks`.
- **Queensland overlay.** Queensland Health's quarterly figures are kept apart from the national figures: they carry no rank, trend or national comparison, and they are never ranked against the national tables.
