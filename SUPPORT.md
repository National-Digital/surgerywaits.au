# Getting help

## A wrong figure

Open a **Data problem** issue. Say which hospital, measure and period, and link the publisher's
own copy where you can, so the difference can be checked. A value that is wrong at the publisher
is the publisher's to correct. The site shows the corrected figure once publicdata.au republishes
it and the site pins the new version.

## Bugs and feature requests

Open an issue with the bug report or feature request template. Please search existing issues first.

## Security issues

Report them privately as [`SECURITY.md`](SECURITY.md) describes, never in a public issue.

## Anything else

Use the [National Digital contact page](https://nationaldigital.com.au/contact/).
